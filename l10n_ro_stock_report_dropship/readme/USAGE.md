This is a technical add-on for the Romania Stock Storage Sheet report
(`l10n_ro_stock_report`): when dropshipping (`stock_dropshipping`) is also
installed, dropshipped stock movements are recognized as a "Dropship"
valuation type and included in the storage sheet report lines. There is no
separate menu or setting to configure; simply generate the storage sheet
report as usual (Inventory > Reporting) and dropship lines will appear
alongside purchase/sale lines.
