Overview

This module adds a wizard that exports, as a single ZIP archive, the files attached to the SPV messages downloaded from ANAF (e-Factura).

The wizard is available as a list action on SPV Messages and lets you choose:

  • Group by VAT - the exported files are placed in a folder named after the fiscal code of the invoice commercial partner, so an archive covering several partners stays readable;
  • What to download - the signed ANAF ZIP file, the ANAF PDF rendering, or both.

It is meant for the periodic hand-over of the received invoices to the accounting department or to an external accounting service.
