Romania - Stock Base

Locations and operations for Romanian consumption and usage giving, and the net weight of the products. It is the Terrabit replacement of the OCA l10n_ro_stock module, written without a dependency on l10n_ro_config.

  • Locations: the location usages Usage Giving and Consume. Moves from or to them count as incoming, respectively outgoing, for the valuation.
  • Company: every company whose fiscal country is Romania gets a usage and a consume location (l10n_ro_usage_location_id, l10n_ro_consume_location_id), created at installation for the existing companies and at creation for the new ones. Locations that already exist are reused, not duplicated.
  • Warehouse: every warehouse of such a company gets the operation types Consume and Usage Giving, with their own sequences (CONS, USAGE). Renaming the warehouse or changing its code renames those sequences too.
  • Net weight (l10n_ro_net_weight) on products, next to the volume.

The field names are the ones of the OCA module, so a database that has it installed keeps its data when this module is installed and the OCA one removed.

Usage

The consume and usage giving locations are created for every company whose fiscal country is Romania, and the matching operation types for every new warehouse of such a company. The fiscal country comes from the Invoicing app, installed together with the module. Enable Storage Locations in Inventory → Configuration → Settings to see the locations menu and the source and destination locations on transfers.

  1. Go to Inventory → Configuration → Locations, remove the Internal filter and look for the two locations of the company: one with the Location Type Consume, one with Usage Giving.

  2. Open the consume location: its Location Type is Consume. The location names come from the language used at installation and can be renamed; the module finds them by their type.

  3. Go to Inventory → Configuration → Warehouses and open the warehouse. With the developer mode on, the Technical Information tab shows Romania - Consume Type and Romania - Usage Giving Type. The warehouses that exist at the installation get them when the module is installed, the new ones when they are created. If they are still missing (the fiscal country became Romania later), change the warehouse Short Name, save, then set it back and save again.

  4. The Consume operation type is an internal transfer from the warehouse stock to the company consume location, numbered with the CONS sequence prefix (<warehouse code>/CONS/00001). The Usage Giving type is the same, towards the usage giving location, with the USAGE prefix.

  5. Create a transfer of type Consume from Inventory → Overview, add the products and quantities, then Mark as Todo and Validate. The quantity leaves the warehouse stock; a Return brings it back, numbered in the same CONS sequence unless a Return Type is set on the operation type. Moves to the consume and usage giving locations count as outgoing for the stock valuation, and moves from them as incoming.

  6. On the product, the Inventory tab shows the Net Weight under the weight, in the same unit.

Changelog

19.0.0.0.1 (2026-10-07)

  • Initial version, replacing the OCA l10n_ro_stock module without l10n_ro_config: consume and usage giving locations, company locations, warehouse operation types and sequences, net weight. The sequences of the consume and usage operation types follow the warehouse name and code when they are changed. While the OCA l10n_ro_stock module is still installed, the net weight and the warehouse operation types are shown only once on the forms. The module depends on account, which gives the fiscal country of the company. The net weight given when a product is created is kept on its variant. The warehouses that exist when the module is installed get the consume and usage giving operation types, and their barcodes follow the warehouse code when it changes.
