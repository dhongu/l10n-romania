This module provides a Stock Aged Report for Romanian localization. It
helps users track the age of inventory by monitoring the last incoming
and outgoing dates for stock quants.

Key features: - Automatically tracks last incoming and outgoing dates
for each stock quant. - Provides a wizard to generate the aged report
for a specific warehouse and date. - Configurable aging intervals (e.g.,
15, 30, 90, 180, 365 days). - Breaks down stock value and quantity into
time ranges (e.g., [1] 0-15 days, [2] 15-30 days, etc.). - Includes
accounting information such as the stock valuation account for each
product. - Provides a pivot and list view for detailed analysis of aged
inventory. - Retroactively updates existing stock quants with historical
data upon installation.

Changelog
=========

19.0.1.0.4 (2026-10-21)
-----------------------

- The report dialog shows the list of locations again, in a *Locations*
  tab, and the list can be edited: the report can be restricted to some
  of the warehouse locations. The list was placed directly in the
  notebook, without a page, so Odoo 19 did not display it.
- Computing the report a second time on the same dialog replaces the
  previous lines instead of adding new lines on top of them, which
  doubled quantities and values.

19.0.1.0.3 (2026-10-21)
-----------------------

- Consultant sheet (``readme/FISA_CONSULTANT.md``, in Romanian) with
  screenshots in ``static/description/``, generated by
  ``tests/test_screenshots.py``: how to read the report (current stock,
  value at current cost, age measured from the last receipt into the
  location), the stock-account comparison and the known limitations.

19.0.1.0.2 (2026-10-21)
-----------------------

- Without a product selected, the report now covers the whole stock of
  the chosen locations. It used to read only the first 10,000 products,
  so on larger catalogues the remaining products were left out silently
  and the total no longer matched the stock.
- The report lines are created in a single batch instead of one by one,
  which keeps the report fast on warehouses with tens of thousands of
  quants.

19.0.1.0.1 (2026-10-09)
-----------------------

- Odoo Apps banner (``static/description/main_screenshot.png``),
  generated from ``banner.json``.

19.0.1.0.0 (2026-10-07)
-----------------------

- Module renamed from ``l10n_ro_stock_age_report`` to
  ``l10n_ro_stock_aged_report``: the former technical name is already
  registered on Odoo Apps by another publisher.
- Databases with the former module installed are migrated automatically
  when the new module is installed: fields, views, actions, menus and
  the last in/out dates on the quants are kept, and the former module is
  removed from the module list (same steps as ``merge_module`` from Odoo
  upgrade-util, without depending on it).

19.0.0.0.4 (2026-09-30)
-----------------------

- Own module icon in the flat style of the Terrabit modules, instead of
  the missing or generic one.
