On a transfer batch whose eTransport notification is **Validated**, the header shows
**Delete UIT**, **Confirm UIT** and **Change Vehicle**, the same dialog as on a transfer. The
events appear in the *UIT Events* table on the batch's eTransport tab.

**Cancel** on a batch with a valid UIT opens the dialog locked on the deletion and cancels the batch as
soon as ANAF receives it, as on a single transfer.
