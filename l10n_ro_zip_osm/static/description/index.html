Romania - Postal Codes, Streets of Small Towns

Străzile orașelor mici din România, pentru nomenclatorul de coduri poștale din modulul l10n_ro_zip.

  • Poșta Română are un singur cod poștal pentru orașele sub 50.000 de locuitori și nu le publică străzile. Modulul adaugă 15.968 de străzi pentru 269 de astfel de orașe (Pantelimon, Voluntari, Lugoj, Râmnicu Sărat, Tecuci, Câmpina, Bușteni și altele), fiecare cu codul poștal al orașului.
  • Numele străzilor vin din OpenStreetMap, sub licența Open Database License (ODbL); vezi Credits.
  • Se instalează automat împreună cu l10n_ro_zip. La instalare, străzile se leagă de județ și, când modulul l10n_ro_city e instalat, de localitate. O stradă deja existentă nu se adaugă a doua oară.

Usage

On a new database, the module is installed automatically with l10n_ro_zip; where l10n_ro_zip was already installed, install it from Apps. It has nothing to configure. It adds the streets of 269 small towns to the postal codes; you use them exactly as the other postal codes of l10n_ro_zip.

  1. See the streets of a small town. As an administrator, go to Contacts → Configuration → Localization → Zip Codes and search the town’s postal code (for Huși, type 735100 and press Enter). The first row, with no street, is the town row of the post office; the other rows are the streets added by the module, all with the same postal code. A town whose code returns a single row is not covered.

  2. Find the street on a partner. On the partner form, pick the city from the list first (1); the state and the town’s postal code follow. Then type the street name in the postal code field right below the city (2), the one with the dropdown arrow. The streets of the partner’s city are offered, each with the town’s postal code. The street names have no diacritics, so typing without them is safer. If a street is missing, pick the town row: the postal code is the same.

  3. Pick the street and save. The ZIP field keeps the town’s postal code (3), with the city (1), the state (2) and the country, and the chosen street fills the postal code field (4); the street and number of the address stay as you typed them. The screenshot shows the form before saving.
