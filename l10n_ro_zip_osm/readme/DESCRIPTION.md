Străzile orașelor mici din România, pentru nomenclatorul de coduri poștale din modulul `l10n_ro_zip`.

- Poșta Română are un singur cod poștal pentru orașele sub 50.000 de locuitori și nu le publică
  străzile. Modulul adaugă 15.968 de străzi pentru 269 de astfel de orașe (Pantelimon, Voluntari,
  Lugoj, Râmnicu Sărat, Tecuci, Câmpina, Bușteni și altele), fiecare cu codul poștal al orașului.
- Numele străzilor vin din OpenStreetMap, sub licența Open Database License (ODbL); vezi Credits.
- Se instalează automat împreună cu `l10n_ro_zip`. La instalare, străzile se leagă de județ și, când
  modulul `l10n_ro_city` e instalat, de localitate. O stradă deja existentă nu se adaugă a doua oară.
