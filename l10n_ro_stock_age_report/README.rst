This module provides a Stock Aged Report for Romanian localization. It
helps users track the age of inventory by monitoring the last incoming
and outgoing dates for stock quants.

Key features: - Automatically tracks last incoming and outgoing dates
for each stock quant. - Provides a wizard to generate the aged report
for a specific warehouse and date. - Configurable aging intervals (e.g.,
15, 30, 90, 180, 365 days). - Breaks down stock value and quantity into
time ranges (e.g., [1] 0-15 days, [2] 15-30 days, etc.). - Includes
accounting information such as the stock valuation account for each
product. - Provides a pivot and list view for detailed analysis of aged
inventory. - Retroactively updates existing stock quants with historical
data upon installation.
