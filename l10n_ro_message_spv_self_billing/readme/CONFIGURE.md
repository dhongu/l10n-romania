1. Create a dedicated sales journal, for example *Self-billing*.
2. On the journal, tick **Number from SPV message**.
3. Record the self-billed document as a draft in that journal, then match it
   with the SPV message ("Find invoice"). The number is filled in from the
   reference of the message; post it afterwards.

Order matters: match first, post afterwards. Posting before matching sends the
document to the SPV, where the customer has already reported it.
