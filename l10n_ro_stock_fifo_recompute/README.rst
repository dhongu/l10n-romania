Recalculează evaluarea FIFO pe locație a mișcărilor de stoc, în ordine
cronologică, și corectează valorile greșite din trecut, cu nota
contabilă aferentă.

Cu FIFO pe locație (``l10n_ro_stock_account``), o ieșire evaluată greșit
(pe stoc negativ necompensat, printr-o operație cu dată în urmă sau
printr-un bug reparat între timp) își păstrează valoarea, iar soldul
conturilor de stoc nu mai corespunde cu valoarea stocului. Modulul refă
calculul și arată, pe fiecare mișcare, valoarea actuală, valoarea
corectă și diferența.

**Cum se recalculează**

- Mișcările efectuate ale fiecărui produs FIFO se parcurg în ordine
  cronologică, cu o coadă FIFO pentru fiecare locație.
- Recepțiile și livrările care nu sunt pe bază de aviz se ordonează după
  data facturii.
- Valoarea intrărilor din facturi și costuri de achiziție rămâne cea
  înregistrată; se recalculează ieșirile, transferurile interne
  (valoarea trece din gestiunea sursă în cea destinație) și retururile
  de la clienți (după valoarea livrării corectate).
- O ieșire făcută pe stoc negativ se evaluează la prețul intrărilor care
  o acoperă în aceeași locație.

**Rularea de probă** nu modifică nimic: arată diferențele pe mișcări și
un control pe fiecare cont de stoc (valoarea stocului recalculată,
soldul contului, soldul după corecție și diferența rămasă).

**La aplicare** se corectează valorile mișcărilor și se postează o
singură notă de corecție, la data aleasă, în jurnalul de stoc:

+----------------------------------+-----------------------------------+
| Diferența                        | Înregistrare                      |
+==================================+===================================+
| Ieșire din exercițiul curent     | pe conturile notei originale a    |
|                                  | ieșirii (de exemplu 607 = 371),   |
|                                  | în roșu dacă ieșirea a fost       |
|                                  | supraevaluată                     |
+----------------------------------+-----------------------------------+
| Ieșire dintr-un exercițiu închis | 1174 în locul contului de         |
|                                  | cheltuieli (OMFP 1802/2014, pct.  |
|                                  | 67 alin. 2)                       |
+----------------------------------+-----------------------------------+
| Transfer între gestiuni          | 371 gestiunea destinație = 371    |
|                                  | gestiunea sursă, indiferent de    |
|                                  | exercițiu                         |
+----------------------------------+-----------------------------------+

O corecție pe 1174 cere de regulă declarația de impozit pe profit
rectificativă pentru anul la care se referă eroarea (art. 19 alin. 3
lit. a din Codul fiscal).

**Legătura cu verificarea stoc–contabilitate**

Modulul ``l10n_ro_stock_account_check`` compară valoarea mișcărilor cu
soldurile din contabilitate și aliniază contabilitatea la valoarea
mișcărilor, considerând-o corectă. Recalcularea FIFO verifică tocmai
dacă valoarea mișcărilor e corectă. Ordinea recomandată: întâi
recalcularea FIFO, apoi verificarea stoc–contabilitate pentru
diferențele rămase.

**Limitări**

- Costul produselor fabricate nu se recalculează după componentele
  corectate.
- Produsele evaluate pe loturi și liniile cu proprietar terț nu se
  recalculează.
- O rulare aplicată nu se poate anula: nota de corecție se stornează
  manual, iar valorile mișcărilor rămân cele corectate.

Usage
=====

1. Deschide *Contabilitate > Contabilitate > Închidere > Recalculare
   FIFO* și apasă **Nou**.
2. Alege produsele sau categoriile de recalculat. Lasă-le goale ca să
   recalculezi toate produsele FIFO ale companiei.
3. Completează **Data corecției** (o dată dintr-o perioadă deschisă),
   **Sfârșitul ultimului exercițiu închis** și **Cont exerciții
   închise** (de regulă 1174).
4. Apasă **Calculează**. În pagina *Diferențe* apare câte o linie pentru
   fiecare mișcare evaluată greșit, cu valoarea actuală, valoarea
   corectă, diferența și conturile notei de corecție. Liniile fără
   conturi (observația „corectează manual") nu se aplică: corectează-le
   manual. Linia „Stoc negativ neacoperit de o intrare ulterioară" se
   aplică, dar arată un stoc negativ încă deschis.
5. În pagina *Control conturi* verifică, pe fiecare cont de stoc, că
   diferența rămasă după corecție e zero. O diferență rămasă nu vine din
   FIFO (de exemplu note vechi pe conturi greșite) și se analizează
   separat.
6. Poți apăsa **Calculează din nou** de câte ori vrei, de exemplu după
   ce schimbi selecția.
7. Apasă **Aplică** și confirmă. Valorile mișcărilor se corectează, iar
   nota de corecție se postează și se deschide din butonul **Notă de
   corecție**.
