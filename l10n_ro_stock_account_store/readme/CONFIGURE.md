1. In *Accounting > Configuration > Settings*, set the **Not Eligible Tax
   Account** (4428) of the company.
2. On the product category of the goods sold in the store, set the **Romania -
   Store Markup Account** (378). The category must use perpetual valuation.
   Optionally set a dedicated **Romania - Store Uneligible VAT Account**
   (e.g. 4428.02), kept apart from the 4428 used for VAT on payment.
3. On the store location (*Inventory > Configuration > Locations*), set
   **Romania - Merchandise type** to **Store**.
4. Set the **Sales Price** and the **Customer Taxes** on the products.
